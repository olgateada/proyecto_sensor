## Requerimientos Funcionales

1. El sistema debe permitir a los usuarios registrarse e iniciar sesión.
2. El sistema debe enviar notificaciones cuando el nivel de ruido supere el límite establecido.
3. El sistema debe mostrar un historial de las lecturas del detector de ruido.
4. El sistema debe permitir al usuario ajustar la sensibilidad del sensor de ruido.
5. El sistema debe generar reportes diarios en formato PDF.

---

## Requerimientos No Funcionales

1. **Rendimiento:** El sistema debe responder a las peticiones del usuario en menos de 2 segundos.
2. **Seguridad:** Todas las contraseñas de los usuarios deben estar encriptadas en la base de datos.
3. **Disponibilidad:** La aplicación debe estar disponible el 99% del tiempo.
4. **Usabilidad:** La interfaz debe ser intuitiva y adaptable a dispositivos móviles (responsive).
5. **Escalabilidad:** El sistema debe soportar hasta 1,000 usuarios concurrentes sin degradar el servicio.

---

## Historias de Usuario

### 1. Registro de usuario
* **Como:** Usuario nuevo.
* **Quiero:** Crear una cuenta en la aplicación.
* **Para:** Poder acceder a las funciones del detector de ruido.

### 2. Configuración de alertas
* **Como:** Usuario registrado.
* **Quiero:** Establecer un umbral límite de decibeles.
* **Para:** Recibir una alerta cuando haya demasiado ruido.

### 3. Consulta de historial
* **Como:** Administrador del sistema.
* **Quiero:** Ver el historial de niveles de ruido registrados durante la semana.
* **Para:** Analizar los patrones de ruido en el área.

### 4. Exportación de datos
* **Como:** Usuario.
* **Quiero:** Descargar un reporte de las mediciones de ruido.
* **Para:** Compartir la información con el equipo de trabajo.

### 5. Personalización de perfil
* **Como:** Usuario.
* **Quiero:** Actualizar mis datos personales y correo de contacto.
* **Para:** Garantizar que las notificaciones lleguen a mi cuenta activa.
